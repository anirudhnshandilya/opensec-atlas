\# Excessive Agent Permissions



\*\*ID:\*\* `THREAT-EXCESSIVE-AGENT-PERMISSIONS`



\*\*Severity:\*\* High



\*\*Status:\*\* Documented



\## Description



Excessive agent permissions occur when an AI agent is granted access or capabilities beyond those required to perform its intended task.



The impact of an agent compromise or manipulation can increase substantially when the agent has unnecessary access to sensitive data, privileged tools, credentials, systems, or irreversible actions.



\## Affected Technologies



\- `TECH-AI-AGENTS`

\- `TECH-MCP`

\- `TECH-AI-CODING-AGENTS`

\- `TECH-BROWSER-AGENTS`



\## Security Impact



Potential impacts include:



\- Unauthorized access to sensitive resources

\- Destructive or irreversible actions

\- Credential misuse

\- Data modification or deletion

\- Lateral movement between connected systems

\- Increased impact from prompt injection or tool compromise



\## Mitigations



Potential defensive measures include:



\- Applying least privilege

\- Restricting available tools by task

\- Separating read and write capabilities

\- Using short-lived credentials

\- Requiring approval for high-impact actions

\- Isolating sensitive resources

\- Auditing agent permissions and tool usage

\- Periodically reviewing granted capabilities
